Glotze

Search and download shows from the public broadcasters of Germany, Austria and Switzerland

Glotze searches the Mediatheken of ARD, ZDF, 3sat, arte, ORF, SRF and more through MediathekViewWeb and saves episodes to your Videos folder for offline viewing. No streaming, no built-in player — Glotze hands you the file and steps out of the way.

Install Source Code

What Glotze Does

  • One search for everything Titles and topics across the MediathekViewWeb catalogue, newest broadcasts first.
  • Pick a quality Low, Medium or HD — whatever the broadcaster offers for an episode.
  • Plain files in your folder Downloads land in ~/Videos/Glotze with a live progress bar. Open them with any video player.
  • Sandboxed As a Flatpak, Glotze can only write to ~/Videos/Glotze and reach the network.

Some videos are geo-blocked to Germany, Austria or Switzerland by the broadcasters. “Glotze” is affectionate German slang for a TV set — roughly “the telly”.

Install

Flatpak Repository

Recommended. Updates arrive through Software or flatpak update.

Install Glotze

or in a terminal:

flatpak install https://tombreit.github.io/Glotze/Glotze.flatpakref

Single File

The bundle from the latest release, without automatic updates.

Download 
flatpak install --user ./glotze.flatpak

Nix

Run it straight from the flake, or pin a release tag.

nix run github:tombreit/Glotze
